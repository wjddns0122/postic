# POSTIC 디자인 레퍼런스 (2026-10-27 조사)

결론: **흐름은 Zara Store Mode + Nike 매장 모드, 톤은 29CM, 숫자·결제·상태는 토스, 직원 대시보드는 Shopify 배지 규칙.**

| 레퍼런스 | 왜 맞나 | 가져올 것 | 적용 화면 |
|---|---|---|---|
| Zara Store Mode (Click & Find, Click & Try) | 매장 체크인 → 그 매장 재고만 보기 → 피팅룸 예약·대기시간·QR 픽업. POSTIC과 기능이 거의 같음 | 매장 모드 헤더, 피팅룸 배정·예상 대기시간, 픽업 QR/번호 카드 | 홈, 상품 상세, 픽업 |
| Nike App 매장 모드 (Scan to Try, Reserve) | 스캔→사이즈 선택→직원 알림→"가져오는 중" 상태 알림 | 요청 상태 단계("직원 확인 → 준비 중 → 준비 완료"), 최대 N개 요청 | 피팅 요청, 픽업, 직원 대시보드 |
| Uniqlo 앱·RFID 셀프계산대 | 태그 자동 인식 계산, 큰 버튼·단순 아이콘 | "인식됨" 피드백의 명료함, 큰 탭 타깃 | 행거, 결제 시트 |
| 29CM | 한국 패션 큐레이션 앱. 최소 색·선, 사진이 주인공, 에디토리얼 타이포 | 사진 크게, 선·그림자 절제, 굵은 타이틀 + 얇은 메타 | 손님 화면 전체 톤 |
| 토스 (TDS) | 한국 사용자가 가장 익숙한 결제·상태 UI | 한 화면 한 행동, 큰 숫자(픽업 번호·금액), 바텀시트 결제, 1px 단위 정돈 | 결제 시트, 픽업 번호 |
| Shopify Polaris 배지 | 매장 운영자용 상태 표기 규칙 | 상태 배지는 한 단어·형용사, 톤(success/caution/critical), 항목 바로 옆, 배지는 클릭 불가(행동은 버튼) | `/admin` 태그 표, 주문 목록 |

## 주의
- Zara/Nike 자료는 2018~2023 기사 기준이라 현재 앱과 다를 수 있다.
- TDS 자료는 앱인토스 범위 라이선스 → 원칙만 참고, 컴포넌트·에셋 복제 금지.
- 29CM 토큰(4px 그리드, 1200px 컨테이너)은 비공식 갤러리 출처.
- 실제 화면 비교: Mobbin, ScreensDesign(Zara 페이지, 일부 유료), App Store 스크린샷.
